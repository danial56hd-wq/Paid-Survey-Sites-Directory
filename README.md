## ✨ المزايا | Features

- 🌍 **4 لغات / 4 languages** — العربية، الإنجليزية، الكردية (كرمانجي)، الأرمنية، مع تبديل فوري للواجهة كاملة.
- 🔍 **بحث وفلترة / Search & filters** — حسب اسم الموقع، طريقة الدفع، وحالة التوفر الجغرافي.
- 💳 **تفاصيل الدفع لكل موقع / Per-site payment info** — عملات رقمية، بطاقات هدايا، PayPal، Payoneer، وغيرها.
- 🤖 **مساعد داخلي / Built-in assistant** — يجاوب على أسئلة حول أي موقع أو طريقة التسجيل (يعمل بدون إنترنت، قواعد مبرمجة مسبقاً).
- 📤 **مشاركة سريعة / Quick share** — عبر واتساب، تيليجرام، أو نسخ الرابط.
- 📲 **قابل للتثبيت / Installable** — يدعم إضافته كتطبيق على الشاشة الرئيسية عند استضافته على رابط ويب حقيقي.
- 🎨 **تصميم داكن أنيق / Elegant dark UI** — بدون أي اعتماد على مكتبات خارجية، ملف واحد ذاتي الاكتفاء بالكامل.
